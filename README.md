# School Health Links

School Health Links는 보건교사의 업무 도구와 기록을 한 곳에 모아 안내하는 개인/업무 링크허브입니다.

홍보용 랜딩 페이지나 복잡한 업무 포털이 아니라, 보건실 도구모음, 연수 신청, 예시 보건실, 전자책, 운영 후기, 문의 링크를 빠르게 안내하는 간단한 링크트리입니다. 따뜻한 베이지 배경, 둥근 카드, 부드러운 그림자 톤을 유지합니다.

## 빠른 시작

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 링크 수정 위치

주요 링크와 화면 문구는 `src/config/linktree.ts`에서 관리합니다.

- `profile`: 서비스명, 첫 화면 소개 문구, 상단 설명
- `cards`: 왼쪽 메뉴와 오른쪽 상세 링크 목록
- `href`: 실제 주소를 모르는 항목은 `#`로 둡니다.
- `thumb`: `public/icons` 안의 SVG 아이콘을 선택합니다.

색상은 `src/config/theme.ts`에서 관리합니다. 기본 베이지 배경과 둥근 카드 스타일은 `src/app/globals.css`와 `src/components/LinkTree.tsx`에서 렌더링됩니다.

## 기본 링크 구성

- 쑤캥 보건실 도구모음
- 지식샘터 연수 신청하기
- 온라인 보건실 예시 살펴보기
- 보건교사 실무 가이드 전자책
- 보건실 키오스크·셀프처치대 운영 후기
- 협업 및 강의 문의

## 운영 메모

- 공개 저장소에는 개인정보, 비공개 링크, API 키, 환경변수를 커밋하지 않습니다.
- 실제 업무 URL이 확정되기 전에는 `#` 값을 사용합니다.
- 학교명, 담당자명, 연락처처럼 공개 범위가 필요한 정보는 게시 전에 확인합니다.
- 링크는 6개 항목을 중심으로 유지하고, 상세 링크는 각 항목당 1~2개 정도로 간단하게 둡니다.
